# 此刻｜macOS 菜单栏私人管家

一个原生 SwiftUI 菜单栏应用。点击顶部的「此刻」图标即可打开毛玻璃建议弹层。

## 构建

需要 macOS 14 或更高版本及 Swift 6 工具链。

```sh
./Scripts/build-app.sh
```

构建产物位于 `dist/此刻.app`。双击即可运行；应用以菜单栏常驻项运行，不显示 Dock 图标。

打包脚本会对完整 `.app` 包进行 ad-hoc 签名，并将签名标识设为 `com.cike.menubar`，以便 macOS 将辅助功能权限绑定到应用 Bundle ID。

## 当前原型行为

- 午餐时段（11:30–13:29）推荐午餐；晚餐时段（16:30–19:29）推荐晚餐；夜宵时段（22:00–00:59）推荐夜宵。三个时段各有不同的单一推荐。
- 微信保持前台且回复输入框持续聚焦 7 秒后，回复建议优先于饭点推荐；读取可见文字前需用户主动开启 macOS 辅助功能权限。
- 微信可见文字只在本机内存中临时处理，不存盘、不上传、不自动发送。回复文案使用本地关键词规则生成，尚未接入 LLM。
- 非用餐时段且没有微信停留场景时，国庆前后显示出行计划；其他时间显示通用回复支持。
- Logo 使用最新的单色开口圆弧「留白」方向。
- 地图入口会打开 Apple 地图；或服务落地页链接，不会自动搜索商家或下单。
- 价格、距离、用户偏好、商家和行程均为示例或待查询状态。微信读取仅限用户授权后的当前可见窗口文字；没有持续记录其他应用行为。

实时个性化推荐仍需连接真实外卖、交通、住宿、票务数据源；微信回复目前是本地规则版。若接入云端 LLM，需另行设计明确的数据授权与传输说明。
